# Animo Blog

Meu primeiro site desenvolvido para praticar e adquirir experiência com **HTML e CSS**.

O **Animo Blog** é um blog fictício voltado para o universo dos animes e mangás. A ideia do projeto é criar um espaço onde os visitantes possam encontrar notícias, informações, categorias e conteúdos relacionados a diferentes gêneros de anime.

## Sobre o projeto

Este projeto foi desenvolvido como uma forma de colocar em prática meus primeiros conhecimentos em desenvolvimento web.

Durante o desenvolvimento, pratiquei principalmente:

- Estruturação de páginas com HTML5;
- HTML semântico;
- Organização de conteúdo com `header`, `nav`, `main`, `section`, `article` e `footer`;
- Criação de formulários;
- Links entre diferentes páginas;
- Inserção e estilização de imagens;
- Organização de listas e conteúdos;
- Estilização de páginas utilizando CSS;
- Uso de fontes externas;
- Flexbox para organização dos elementos;
- Criação de cards e categorias;
- Efeitos de `hover` em elementos.

## Sobre o Animo Blog

O blog possui diferentes páginas e seções relacionadas a animes, incluindo:

-  Página inicial;
-  Notícias;
-  Categorias por gênero;
-  Informações sobre o blog;
-  Página de contato;
-  Redes sociais.

O projeto também possui páginas específicas para diferentes categorias de animes, permitindo organizar os conteúdos de acordo com seus gêneros.

##  Tecnologias utilizadas

- **HTML5**
- **CSS3**
